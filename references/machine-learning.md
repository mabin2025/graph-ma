# 机器学习与 Notebook 专项检查

仅在数据分析、机器学习或 Notebook 项目中读取。按真实实验链路分析，不套用在线服务结构，也不自动执行完整训练。

## 数据探查与特征筛选

- 确认训练、验证、测试各自的来源、行列数、标签、缺失值和匿名字段边界。
- 核实分布比较用的是人工看图、距离度量还是统计检验，不能把人工固定删列描述成自动筛选算法。
- 区分特征与目标的相关性、特征之间的相关性以及其他相似度；明确真正触发删列的条件。弱线性相关不等于没有非线性预测价值。
- 优先用核心筛选代码配分布图或热力图解释“看什么、怎样判断、保留什么”，不要堆叠全套探索图。

## 预处理、异常过滤与 PCA

- 追踪缩放、缺失处理、变换、异常过滤和降维顺序；区分绘图演示中的临时数据与实际落盘数据。
- 核实 fit 使用哪些样本、transform 使用哪些样本。缩放、Box-Cox、PCA 与标签相关筛选是否先于验证切分，要明确说明。
- 区分归一化、标准化、分布变换、正则化和 PCA；不能把 Min-Max 或标准化说成使数据服从正态分布。
- 异常筛选说明检测器、阈值、残差是否来自训练内预测或 OOF、多个检测器如何合并、最终删除哪些行。缓存行数不是固定参数。
- PCA 核对真实维数、白化、训练与测试是否共享变换对象；注释、历史输出和数组形状冲突时分别标注。
- 检查变换参数、列顺序和对象是否持久化，不能把保存变换后的数组说成保存了完整推理流水线。

## 训练与评估

- 核实模型的真实类、训练输入、数据切分比例与索引、随机种子、交叉验证方法和搜索范围。
- 区分 MSE、RMSE、R²、训练分数、验证分数、CV 均值与标准差；学习曲线的默认 scoring 需要按实际调用确认。
- 检查对照实验是否共享验证样本与预处理，验证阶段和最终导出阶段是否采用同样超参数。条件不一致时不能单独归因于某个模型或 PCA。
- 历史输出、代码注释、当前缓存、本次运行分别记录；单凭旧排行榜或注释不能宣称当前性能。
- 检查标签泄漏、重复样本、主体隔离或时间隔离是否影响评估。改进建议与当前已实现逻辑分开。
- 仅在必要且授权范围内运行小规模验证；不为补图自动启动完整网格搜索、昂贵训练或外部提交。

## 融合与产物

- 区分等权平均、加权平均、bagging、stacking 与 blending，依据实现而不是章节名判断。
- 核实成员模型、权重来源、是否按分数过滤、OOF 构造及融合后是否单独评估；单模型较好不能证明融合提升。
- 追踪真实文件依赖，区分实验阅读顺序、变量复用和实际调用关系。
- 核对输出样本数、测试行序、ID、舍入与文件格式；写出结果不等于已提交或已部署。

## Notebook 与结果图

按文件顺序引用单元格；不要把执行编号当成稳定编号。检查语法、变量覆盖、乱序依赖、库版本与注释冲突，但不为文档任务擅自修业务代码。

优先直接提取 Notebook 保存的少量关键图，保留原始结果并注明文件与单元格。每张图说明坐标、标记、关键观察和局限；图太密时选择更有代表性的原始输出，不用低清缩略图充数。没有真实结果时可只保留流程和代码，不制造实验成绩。

## 可选复盘问题

从项目确实采用的机制中挑选问题，例如为什么缩放、为何正则化、PCA 的取舍、何时使用时间切分、等权融合是否必然提升。采用“原理结论 → 本项目证据 → 适用边界”的短回答；不要把示例问题作为所有项目的固定题单。
