# graph-ma

基于真实源码，用项目主图、核心子模块 SVG 和简洁中文说明，帮助你理解陌生项目。

## 适用场景

- 项目接手、架构梳理、调用链和数据流分析。
- 深入理解 Agent、RAG、记忆、规划路由、工具执行和任务调度。
- 将复杂项目整理成可追溯到源码的图文解读文档。

## 核心原则

先确定项目主图，再深挖复杂子模块，最后按图的结构组织正文。所有主要链路、路由条件和指标值都需要源码证据；明确区分源码确认、合理推断和运行待验证项。

默认产出一份 Markdown、一张项目主图 SVG，以及按需生成的核心子模块 SVG。SVG 需要进行 XML 和渲染检查。默认仅写入指定文档和图形资产，不修改业务代码。

## 使用示例

在支持加载此技能的 Agent 中，提供代码库位置、输出位置和关注点：

```text
使用 graph-ma 分析当前代码库。
重点解释请求主链路、路由条件、数据存储和失败回退路径。
输出 docs/project-overview.md，SVG 放到 docs/assets/。
每个关键结论都给出源码位置。
```

如需先审阅主图，可以明确要求：

```text
使用 graph-ma 解读这个项目，先完成项目主图并等我确认，
确认后再继续绘制子模块图和编写正文。
```

## 文件结构

```text
graph-ma/
  SKILL.md
  agents/
    openai.yaml
  README.md
```

`SKILL.md` 是技能入口，位于仓库根目录；`agents/openai.yaml` 提供显示名称、简介和默认提示词。

本仓库不包含独立可执行程序或预生成的项目分析结果。实际分析需要宿主 Agent 能读取目标代码库、写入输出文件，并使用浏览器或其他 SVG 渲染器完成视觉检查。
